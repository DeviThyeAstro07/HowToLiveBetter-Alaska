# 高性价比人生指南 · 阿拉斯加版

《高性价比人生指南》美国阿拉斯加版：235 条按性价比排序的生活决策建议，含 PFD、极寒求生、野生动物安全、黑暗季心理健康等阿拉斯加特色内容。

- 节内条目按性价比从高到低排列；不用全做，挑一两条即可
