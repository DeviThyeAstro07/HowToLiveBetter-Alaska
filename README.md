讲怎么活得久、怎么少生病，出了意外怎么救——在阿拉斯加，这还包括**极寒、黑暗季、熊和驼鹿、地震海啸、偏远地区求生**。讲怎么少花冤枉钱，哪些事会让人被骗、摊上官司。讲没工作没钱时在**阿拉斯加**能领什么：PFD 分红、取暖补助、扩大后的 Medicaid。也讲租房买房、开 LLC、看病省钱、恋爱结婚生孩子。

## 这本书的特别之处

- **235 条建议**，每条写明**成本 / 说人话 / 收益 / 证据等级 / 来源**——来源只引期刊论文（附 DOI）和官方文件（CDC、ADF&G、IRS、阿拉斯加政府官网），不引二手转述
- **按性价比排序**：每节内条目按"花掉什么 vs 换回什么"从高到低排，不用全做，挑一两条就行
- **阿拉斯加本地化**：PFD 永久基金分红、Denali KidCare、LIHEAP 取暖补助、最低工资阶梯、押金上限 2 个月、熊喷雾、黑暗季 SAD 光疗、空中医疗转运……制度与自然安全内容全部按阿拉斯加现行规定重写并核实过官方来源
